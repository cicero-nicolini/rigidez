# Exemplos do projeto rigidez

Os exemplos são organizados por finalidade, sem alterar a numeração original.

- `analise_estrutural/`: análise matricial, deslocamentos, solicitações e reações.
- `dimensionamento/`: verificações e dimensionamento de elementos de concreto armado (a organizar).
- `vigas_com_aberturas/`: modelos com furos ou aberturas (a organizar).

## Exemplo 1

Localização: `analise_estrutural/exemplo1/`.

A partir da raiz do projeto:

```powershell
python exemplos/analise_estrutural/exemplo1/exemplo1.py
```

O caminho antigo `python exemplos/exemplo1/exemplo1.py` continua disponível por meio de um encaminhador de compatibilidade.

Os arquivos `.ftl` devem ser abertos no FTOOL, conforme a instalação local.
